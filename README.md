A haiku about debugging in strict 5-7-5: a stray print left in production leaks my notes to the logs, and the users read them too.

> One print left in prod
> it leaks my notes to the logs
> users read them too

72 characters, three lines, 5-7-5 syllables. The program writes the haiku as plain text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), then reads it back and verifies the gate: exactly three lines, syllable shape 5-7-5, at most 200 characters. Standard library only.

## Run it

```sh
python3 main.py
```
